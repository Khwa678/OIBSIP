WebDev · Level 1 · Task 1 — Landing Page

Intern Track: Web Development & Designing Project: Nimbus — a fictional cloud storage brand landing page

Objective

Build a visually polished static landing page for a product/brand, establishing foundational HTML/CSS layout skills (per OIBSIP Task Card).

Tech Stack
HTML5
CSS3 (Flexbox + Grid, no JavaScript)
Google Fonts (Poppins for headings, Inter for body)
Features Implemented
 Sticky navigation bar with 4 nav links (Features, About, Testimonials, CTA)
 Hero section with headline, subheadline, and call-to-action button
 Two distinct content sections: Features (3-card grid) and About
 Bonus third section: Testimonials
 Footer with contact info and placeholder social links
 Consistent indigo/neutral colour palette across all sections
 Fully responsive layout (breakpoints at 768px and 480px) using CSS Grid/Flexbox
 No element overlap — consistent padding/margin/box-sizing throughout
 Typography hierarchy: distinct heading font (Poppins) vs. body font (Inter), multiple font sizes for h1/h2/h3/body
